## 1. 🧭 **Архитектурная модель**

### 💡 Тип: **Модульный монолит**

* Разделение на слои (UI / бизнес-логика / данные / интеграции) реализовано, но в рамках одного процесса.
* Telegram выступает в роли основного пользовательского интерфейса.

```
          [User]
            │
         Telegram Bot
      (bot.py / telegram.ext)
        ┌─────┴─────┐
        ▼           ▼
register_wallet   send_crypto
(registre_wallet) (connect_polygon)
        │                 │
        ▼                 ▼
   SQLite DB         Blockchain API
  (users.db)      [Polygon / Tron (частично)]
        ▲
        │
 database.py (init)
```

---

## 2. 🧩 **Интерпретация слоёв**

| Слой            | Назначение                            | Файлы                                      |
| --------------- | ------------------------------------- | ------------------------------------------ |
| UI (Telegram)   | Ввод пользователя и команды           | `bot.py`                                   |
| Бизнес-логика   | Генерация кошельков, отправка токенов | `registre_wallet.py`, `connect_polygon.py` |
| Хранение данных | Хранение пользователей и кошельков    | `users.db`, `database.py`                  |
| Инфраструктура  | RPC, ключи, Telegram-токен и т.д.     | `.env`, Web3, TronPy                       |
| Тесты / отладка | Простые проверки                      | `test_wallet.py`, `tets.py`                |

🎯 **Цель:** сделать Telegram-бот, который визуально и функционально покажет идею “пластик → токены → прокачка”, пусть даже без настоящего блокчейна.

### 1️⃣ `/recycle`: сдача пластика = начисление ECO

* Команда `/recycle <кг>`
* Добавить `eco_balance` и `plastic_total` в БД
* На каждый кг начислять X ECO
* Команда `/balance` — текущий счёт

📈 **Цель:** показать, как действия → награда

---

### 2️⃣ `/profile`: XP и уровни

* Добавить `user_xp`, `user_level`
* Каждое действие (рецикл) = XP
* Команда `/profile` с emoji или ASCII визуализацией

👤 **Цель:** персонализация, мотивация расти

---

### 3️⃣ `/achievements`: NFT-заглушки

* Таблица достижений
* При событиях (напр. 100 ECO) — выдавать ссылку на “NFT”
* Команда `/achievements` показывает прогресс

🏅 **Цель:** демонстрировать вознаграждение и коллекции

---

### 4️⃣ `/sendeco`: псевдотранзакции

* ECO передаётся между пользователями
* Таблица `eco_transactions`
* Команды: `/sendeco <id> <кол-во>`, `/eco_history`

💰 **Цель:** создать видимость экономики

---

### 5️⃣ UI/UX апгрейд

* Аватарки “эко-героя”
