2. Функциональная Интерпретация
bot.py
Центральная точка входа Telegram-бота.

Реализует команды:

/start — приветствие;

/wallet — создание/получение кошельков через register_wallet;

/send — отправка токенов через send_crypto.

Активирует асинхронный Telegram-бот (telegram.ext.Application).

registre_wallet.py
Генерирует Ethereum (через secrets) и Tron (через tronpy) кошельки.

Сохраняет их в SQLite-базу users.db.

При повторных вызовах возвращает существующие кошельки, избегая дублирования.

connect_polygon.py
Асинхронно отправляет токены:

через web3.py — по сети Polygon;

через tronpy — по сети Tron (реализация Tron не предоставлена в коде).

Зависит от переменных .env.

database.py

telegram_id

eth_wallet

tron_wallet

Используется косвенно — предположительно вызывается один раз вручную.

.env

токен бота,

приватные ключи для Polygon и Tron,

RPC-адреса для взаимодействия с блокчейнами.

Тесты (test_wallet.py, tets.py)
Простая проверка функции register_wallet() для разных Telegram ID.
